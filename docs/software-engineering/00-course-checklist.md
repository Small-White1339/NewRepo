## 交作业前必须核对

- 文中“当前实现”与软件实际操作一致；“建议方案”“待补材料”已由组员确认。
- 引用图有编号、名称、用途说明；DFD、用例、状态、顺序图没有混用。
- 能从需求追到页面 / 接口、代码位置和测试；没有把 API 存在写成前端页面已经提供。
- 报告包含真实调研、分工、测试证据和配置管理截图，不能只堆图凑页数。
- 公开职业资料不写成真实投递者；不把本地演示账号、数据库内容或真实密钥提交到公共仓库。
